# Idomsintroduce · 泵小智产品介绍

机泵行业（IDOMS）产品能力独立演示站。品牌：**泵小智**。

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
python3 -m http.server 8080
# 访问 http://localhost:8080
```

## 页面

- `index.html` — 首页（机泵行业方案 + 产品能力）
- `module-detail.html` — 模块详情
- `assets/bengxiaozhi-logo.png` — 泵小智 LOGO

## 系统演示

默认跳转：https://zb.mes.iipcloud.com/login

## 说明

本仓库由云智产品介绍平台的机泵行业内容独立拆出，并将「云智」相关品牌信息替换为「泵小智」。
